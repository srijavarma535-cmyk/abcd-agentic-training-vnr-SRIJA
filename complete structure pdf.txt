How the layers connect (the spine of the course)

Foundation → Language — NN is the engine inside every LLM. You can't understand why an LLM works without knowing what a neural network is.
Language → Infrastructure — Once you have an LLM, you need somewhere to run it reliably. Docker gives that isolation; N8N gives a visual way to wire LLMs to the world; MCP gives a standard "plug" between any LLM and any tool.
Infrastructure → Agent Primitives — Now you can give the LLM tools to call, turn it into an agent, let agents pass work to each other (handoffs), and add guardrails so they don't go rogue.
Agent Primitives → Frameworks — Instead of wiring tools and handoffs by hand, frameworks (LangChain, LangGraph, CrewAI, AutoGen, OpenAI SDK) give you pre-built patterns and state management.
Frameworks → Workflow Patterns — With frameworks in place, you learn the reusable design patterns: chain, route, parallelize, orchestrate, evaluate-optimize. Lab 2 is where you code these.
Workflow Patterns → Multi-model + Advanced tools — Real production agents mix different models (vision, code, text), need live web search (Serper), and need to alert humans (Pushover). LangSmith enters here for debugging.
All layers → Observability — Tracing cuts across everything. Every agent step is logged so you can see what the LLM decided, which tool it called, and where it failed.
